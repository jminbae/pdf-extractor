# 1.2.6 실제 문서 사용 흐름 보완

기준은 공개·설치된 v1.2.5, 기록 HEAD `47bdaf3`입니다. 사용자가 제보한 실제 13쪽 PDF와 71장 PPTX의 사본으로 검증합니다. 원본·기존 저장 결과·설정은 검사 중 변경하지 않습니다. 생성물은 프로젝트 DevCache 또는 TEMP에 둡니다.

1. 모든 파일 체크를 허용하고, 선택한 완료 파일도 재추출합니다. 실행 중인 동일 파일은 작업 관리자에서 중복 차단합니다.
2. 목록 왼쪽의 폴더 패널에서 문서·바탕화면·다운로드·드라이브와 하위 폴더를 오갑니다. 뒤로·앞으로·상위 이동을 제공하고 주소 입력과 폴더 추가 버튼은 제거합니다. 파일은 열기(Ctrl+O) 또는 드래그로 선택하며 단일 파일은 바로 원본을 표시합니다. 폴더 탐색과 실행 중인 작업의 원본 경로를 분리합니다.
3. PPTX는 세로 연속 스크롤로 읽고 가까운 슬라이드만 준비합니다. 공개 렌더러의 API와 기존 격리·검색·확대·위치 연결을 유지합니다. PDF 변환은 보조 동작으로 내립니다.
4. 현재 문서에서 추출하고 저장이 끝나면 원본 옆에 MD를 표시합니다. 다른 파일 완료로 읽는 문서를 바꾸지 않습니다.
5. 이미지 안의 글자도 기존 로컬 Tesseract로 추출해 MD 본문에 보존합니다. native 텍스트·표와 그림 자체도 유지하며 OCR 출처와 누락·실패를 기록합니다.
6. 90% 제보는 실제 설치본의 새 SDK 추출과 기존 캐시 경로를 각각 실행하고 단계별 진행을 검증합니다. 진행 수신 형식 등 확인된 결함만 수정하며 재현하지 못한 정체를 해결했다고 보고하지 않습니다.

역할: root는 폴더 API·통합·이미지 OCR·빌드/배포, `reader_ux_v126`은 UI/연속 슬라이드, `stall_diagnosis`는 실제 PDF/SDK 진행, `implementation_review`는 독립 검수입니다. 제품 편집 뒤 회귀와 실제 파일 전체 추출·사용 조작을 확인하고, 새 버전 공개·설치·자료 보존까지 이어갑니다.

## 소스 검증과 최종 후보

- 최종 Python 회귀 338개/93.396초 PASS. 단일 열기는 부모 폴더로 이동하고 원본을 표시하며, 여러 파일 열기는 해당 파일만 체크합니다. 추출 중 폴더 이동은 기존 작업·원본 경로·출력 위치를 바꾸지 않습니다. Windows KnownFolder는 공식 `KF_FLAG_DONT_VERIFY`로 경로만 얻고 실제 탐색 시 존재를 확인합니다.
- 실제 13쪽 논문의 소스 앱 추출은 14.578초에 저장됐고, 대조 화면의 본문 73,047자와 표 3개(30/18/33행), 원본 왼쪽·MD 오른쪽을 확인했습니다. 설치 1.2.5에서 지속 90% 정체는 재현하지 못했습니다. 확정한 SDK stderr 진행 수신 결함을 수정했으며 이를 정체의 유일 원인으로 단정하지 않습니다.
- 실제 71장 PPTX 전체 소스 추출은 104.532초, 본문 10,225→93,187자, OCR 4,288문단입니다. 원본 그림 81개/고유 OCR 그림 80개를 보존했고 OCR 실패는 0개입니다. 51문단은 엔진 좌표가 이미지 밖이어서 텍스트와 논리 출처만 보존하고 불확실성을 기록합니다. OCR 정확도 100%를 뜻하지 않습니다. `pptx-image-ocr-diagnosis/actual-verified/{receipt,verification}.json`.
- 실제 PPTX 71장 연속 스크롤·검색 강조·텍스트 선택·Ctrl+휠을 확인했습니다. 화면 가까운 2장만 렌더하고 지나간 장은 높이를 보존하며 해제합니다. 늦은 비동기 응답이 현재 장을 바꾸거나 닫은 장의 오류를 표시하지 않도록 회귀를 추가했습니다.
- 사용자 추가 요청으로 기본 창 1040×760/최소 720×520/강제 최대화 제거, 좁은 목록의 폴더 패널 자동 접기·명시적 열기/닫기를 적용했습니다. 620/720/800폭에서 대조는 좌우를 유지하고 추출 버튼과 파일 목록에 접근할 수 있습니다.
- 생산 소스 동결: UI `139cbc579e491da841364398f61bbf196a3d75e06db737dac289c54982542813`, frame `be5a5b59514727b5413b89f62e483ee3fd4b68364cea0ed957cd114997ce6e67`. 주소창 후보 빌드는 baseline이며 배포하지 않습니다. `production-input-pins-1.2.6-sidebar-final.json`의 60개 소스를 기준으로 새 전체 빌드·정확한 EXE QA를 진행합니다.
- 사용자 STORE 전체 2,373파일/출력 전체459파일과 프로그램2개를 별도 경로에 복사·해시 대조했습니다. 기존 백업·원본·rollback을 포함한 6,445개 검사가 통과했습니다. 설치 후 일반 앱 실행 전에 프로그램 원본2개만 제외한 6,443개를 다시 대조합니다. 백업·실패 증거를 지우지 않습니다.
