# 1.2.7 탐색기·원본 미리보기·수식 추출 보완

사용자 확정 흐름은 **왼쪽 폴더 트리 / 가운데 폴더·파일 목록 / 오른쪽 현재 문서**입니다. 문서 한 번 클릭은 원본 미리보기, 같은 패널에서 추출·MD 보기로 전환합니다. 목록의 체크는 여러 파일 추출용으로 유지합니다. 오른쪽 목록에는 상위 `..`, 하위 폴더, 지원 문서 순서로 표시합니다. 마우스 뒤로/앞으로와 기존 보기 위치를 연결하고 상단 페이지 입력·화살표를 제거해 하단 중앙에 읽는 위치만 작게 표시합니다.

실제 원인은 별도로 확인했습니다. TXT는 추출을 지원하지만 PDF 원본 변환 경로에서 지원하지 않아 미리보기가 거절됐습니다. `partial`을 일괄 “확인 필요”로 표시해 OCR 사용과 저장 성공을 혼동시켰습니다. PPTX 그림은 정확한 원본 shape ID를 버리고 native 문자열 검색만 시도해 그림/그림 속 OCR 위치 연결이 끊겼습니다. 수식 사진은 원본 수식 XML이 없으며 일반 Tesseract가 합계기호를 `>` 등으로 오인식했습니다. 글자 수·그림 보존만으로 수식 정확성을 검증하지 않습니다.

구현 순서는 다음과 같습니다.

1. 원문 인코딩·CRLF·탭·리터럴을 보존하는 텍스트 미리보기와 정확한 Unicode 범위 검색. 원본·MD를 추출 없이 읽고 원본 revision이 달라지면 이전 위치를 거절합니다.
2. 읽기 전용 폴더 트리 지연 확장 API와 3패널·마우스 이력·최소 위치 표시. 폴더 이동 중 기존 작업·원본 경로·출력 위치를 바꾸지 않습니다.
3. 신규/이전 PPTX 정본의 정확한 slide/shape ID와 원그림 SHA·crop·변환을 공개 렌더러 DOM과 연결합니다. 원본 지문이 다른 경우 추측하지 않습니다.
4. 공개 수식 OCR을 실제 제보의 수식·비수식 그림에 먼저 시험합니다. 모델을 쓴다는 사실과 실제 정확도를 구분하고, 환각 텍스트나 임의 수식 하드코딩을 해결책으로 삼지 않습니다. 문서를 외부 API로 전송하지 않습니다.
5. 회귀·실제 파일·동일 최종 EXE·공개 자산·표준 설치·기존 자료 보존을 독립 검수합니다. 기존 공개1.2.6 및 실패 증거를 유지합니다.

소유 범위: root는 app.py·텍스트 범위 모듈·공개 수식 엔진 조사/통합·빌드/배포, reader worker는 UI/프레임/실입력 회귀, debugger는 원본 미리보기·그림 출처·실42장 진단, reviewer는 독립 검수입니다. 생성물은 `cache_root/260725 PDF 추출`과 소유 TEMP에 두고 사용자 자료·기존 생성물은 이동하거나 지우지 않습니다.

추가 확정: 뷰어를 우선합니다. 설치된 Word/PowerPoint/Excel/한글 없이 열고, 위치 breadcrumb·현재 폴더 파일명 검색·리스트/썸네일 전환을 탐색기에 맞춥니다. 첫 장만이 아니라 현재 배율에서 viewport를 채우는 페이지와 인접 구간을 먼저 준비합니다. TXT/MD는 추출 불필요하므로 모든 실행 진입점에서 제외합니다. DOCX/XLSX는 기존 python-docx/openpyxl의 범위 제한 내용/셀 창을 바로 읽고, PDF 변환은 원본 조판 대체 표시로 남깁니다. 썸네일은 PDF 첫 페이지 또는 패키지의 기존 thumbnail만 사용하며 전체 변환을 시작하지 않습니다. 진행 중 선택이 바뀐 요청은 경로 검증으로 혼입을 거절하고 이전 무거운 작업은 협력 취소합니다.
