# 문서 뷰어 · PDF Extractor

Windows에서 여러 문서를 빠르게 열어 읽는 로컬 문서 뷰어입니다. 별도 Word·PowerPoint·Excel·한글을
실행하지 않고 문서를 선택해 읽으며, Markdown 추출은 필요할 때 사용하는 보조 기능입니다.

왼쪽 폴더 트리, 가운데 파일 리스트·썸네일, 오른쪽 원본 미리보기로 구성합니다. 위치 표시줄과
현재 폴더 검색, 키보드 파일 이동, 마우스 뒤로·앞으로를 지원합니다. 파일을 한 번 누르면 오른쪽에
열리고, 두 번 누르면 문서 영역을 넓혀 읽습니다. 열기(Ctrl+O)와 드래그로도 파일을 고를 수 있습니다.
기본 목록에는 추출 대기·저장 완료 같은 상태를 상시 표시하지 않습니다.

PDF·PPTX·HWP·HWPX는 연속 스크롤하며 현재 화면과 가까운 페이지만 준비합니다. HWP/HWPX는
동봉한 rHWP의 원본 쪽 렌더링과 쪽별 원문 검색을 사용합니다. DOCX·ODF·EPUB 등은
본문·표·그림의 내용 창을, XLSX·ODS는 필요한 셀 창을 바로 읽습니다. TXT는 원문을 그대로 읽고,
MD는 로컬 상대 이미지와 함께 읽거나 코드로 볼 수 있습니다. 모든 원본은 읽기 전용이며 문서 내
찾기·Ctrl+휠 배율·라이트/다크 모드를 제공합니다. 이전 파일의 오래된 미리보기 작업은 취소하고
현재 선택을 우선합니다. 내용 보기는 원본의 모든 조판·도형·수식을 재현하는 방식은 아닙니다.

상단의 `MD 추출`·`MD 보기`에서 선택한 문서의 정보를 Markdown으로 모을 수 있습니다.
TXT·MD는 추가 추출이 필요하지 않습니다. 추출은 별도 프로세스로 실행하므로 다른 문서를 계속
읽을 수 있습니다. PPTX 이미지 안의 글자도 로컬 OCR로 읽고 원래 그림을 함께 보존합니다.

모든 PDF는 공식 PyMuPDF Markdown 엔진으로 시작하며 다단·표·그림·스캔 구조를
처리합니다. 서지정보 조회를 본문 추출의 선행 조건으로 삼지 않습니다. 문서 추출은
문서마다 화면과 별도 프로세스로 실행해 다른 문서를 읽고 검색할 수 있습니다.
동시 실행은 CPU에 따라 최대 10개이며 메모리·CPU 여유가 부족하면 대기열에서
기다립니다. 실행 중에도 문서를 추가할 수 있습니다. HWP/HWPX는
rHWP를 사용합니다. 로컬 OCR과
레이아웃 모델은 사용하지만 유료 LLM/API에 문서를 보내지 않습니다.

기본 결과 위치는 사용자의 실제 문서 폴더 아래 `문서 추출기`이며 설정에서 바꿀 수
있습니다. 그림은 결과 폴더의 `assets` 아래에 상대 경로로 저장됩니다. 원본은
수정하지 않습니다. 복잡한 병합 표는 Markdown 파일 안의 HTML 표로 보존합니다.
실제 MD 작업의 실패나 추출 제약은 해당 작업의 안내에서 확인합니다.

RTF 내용 보기는 동봉한 striprtf를 사용합니다. 구형 XLS/MSG의 추출이나 다른 Office 문서의
PDF 대체 표시는 추가 로컬 도구가 필요할 수 있습니다. PPTX의 복잡한 도형이나 글꼴이 다르게
보이면 대체 표시를 선택할 수 있으며, LibreOffice 설치 여부와 글꼴에 따라 결과가 달라집니다.
